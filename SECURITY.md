# Security reports

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/jake-reinders/lighter-image-oss/security/advisories/new).

Do not publish credentials, user data, or exploitable details in issues. Include the affected revision and reproduction steps using synthetic data. Do not test against the original hosted service or anyone else's infrastructure without permission.

This is a source-code project, not a hosted service. Operators are responsible for their deployment configuration and infrastructure.

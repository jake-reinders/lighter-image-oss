# Contributing

Keep changes focused and describe the problem, resulting behavior, and verification. Run both test suites and builds listed in README.md when changing shared code.

Use synthetic data and your own infrastructure. Do not commit populated environment files, credentials, private images, database exports, or generated build directories. Edit `src/upload.ts` rather than its generated bundle.

This repository distributes source code only. Contributions must not depend on the original hosted service, branding, editorial assets, or private infrastructure. Use your own Git author identity.
